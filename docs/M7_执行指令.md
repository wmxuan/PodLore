## 三、M7 执行要点（Trae 注意）

### 1. 后端 `/api/home`（聚合数据）

```json
{
  "word_cloud": [{"word": "护发", "weight": 12}, ...],     // 高频主题词
  "footprint": [{"date": "2026-08-30", "count": 5}, ...],  // 近 30 天沉淀量
  "books_recent": [{"id": 3, "title": "...", "cover_url": "...", "chapters": 1, "paras": 64, "created_at": "..."}],
  "stats": {"books": 3, "annotations": 5, "notes": 2, "episodes": 1}
}
```

**数据来源（全部真实，禁止假数据）**：
- `word_cloud`：从标注（annotations.note_text）+ 摘要（episodes.book_summary）提取高频词——**jieba 分词 + 词频**（标注/笔记加权：标注 2 倍权重），取 top 20-30
- `footprint`：近 30 天按天聚合——沉淀量 = 当天创建的书数×3 + 标注数×1 + 笔记数×2（简单加权，文档说明口径）
- `books_recent`：list_books 前 5 本（时间倒序，已有接口）
- `stats`：books 总数 / annotations 总数 / notes（note_text 非空）总数 / episodes 总数

### 2. 前端首页（四模块，ins 布局）

- **词云**：词的大小 = weight，低饱和色块（雾蓝/灰蓝/燕麦/陶土浅色）+ 大圆角；**点击词 → 跳 `/search?q=词`**（直达语义搜索——首页没有搜索框，词云就是入口）
- **足迹热力图**：近 30 天网格，莫兰迪色阶（浅灰→雾蓝→灰蓝→陶土橘），颜色深浅=沉淀量；悬停显示日期+数量
- **书架画廊**：最近的书封面墙（3 列网格，aspect 3:2，胶片感滤镜），点击进书
- **数据成就**：四个数字（书/标注/笔记/单集），大号 Light 字体，一行展示
- **布局**：ins 3 列网格（大屏）→ 2 列 → 1 列（响应式）；大留白；毛玻璃导航延续
- **空态**：无数据时展示引导（「导入第一集开始沉淀」→ 跳编辑页示例）

### 3. 路由调整
- `/` → Home（当前 `/` 是 Books，调整：`/` 首页，`/books` 书架，导航加「首页」入口）
