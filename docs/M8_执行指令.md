## 三、M8 执行要点（Trae 注意）

### 1. 冒烟脚本（smoke_pipeline.py）
- 一键跑通第一期全链路：真实链接 → 抓取 → 转写（可跳过，用已有数据）→ 加工 → 成书 → 标注 → 搜索 → 首页四模块
- 每步输出状态（✓/✗）+ 耗时
- 供用户/面试官快速验证「这个产品真的能跑」

### 2. 端到端验收（用户操作，Trae 给指引）
- **用户本人操作**：用 5 本真实播客（建议不同话题，如纵横四海 + 半拿铁）跑全流程
- **验收重点**：
  - 阅读器：边听边读边标注（播放同步/划线/笔记/选中搜索）
  - 语义搜索：搜你听过的内容能搜到
  - 首页：词云从「摘要提取」变成「标注驱动」（**先划线再回首页看词云变化**——验证数据飞轮）
  - **评测集补跨话题 query**（M6 遗留项）：导入不同话题书后，补「跨话题」query（如「雷军的创业经历」应只命中商业书），重跑评测验证区分度

### 3. README 完善
- 快速开始：install.sh + start.sh 步骤
- **功能截图**：首页/阅读器/搜索页 3 张（用户提供或 Trae 说明截图命令）
- 架构说明：一期技术栈 + 里程碑概览
- 评测报告：M6 的 40 条评测结果（含 Recall 诚实性说明——三本同话题书，区分度待跨话题验证）
- 风险声明：本地使用/版权/数据不出本机（PRD §9/§10）

### 4. 面试展示准备
- 3 张关键截图：首页知识宇宙 / 阅读器（边听边读标注）/ 搜索页（语义召回）
- 演示脚本：从粘贴链接到搜索观点，3 分钟内讲完（Trae 给脚本草稿，用户润色）
