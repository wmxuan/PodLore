## 二、实现亮点（评审重点）

### 1. 「不抢滚动」处理（我预判的风险点，处理到位）
- 手动滚动（wheel/scroll/keydown）期间暂停自动跟随 800ms
- 段落已在可视区时不强制 scrollIntoView
- 用户点播放/拖进度条立即恢复跟随——交互细腻

### 2. 标注锚定（本项目根基，两端闭环）
- 前端：TreeWalker 纯文本累计偏移——不随 mark/span 等 DOM 变化漂移
- 后端：insert_annotation 6 项严格校验（offset>0/段不存在/跨书/越界/end≤start）——拒绝静默失败
- **「书冻结 + 偏移锚定」从设计到实现完整闭环**

### 3. 搜索占位（正确分层）
- M5 用 SQLite LIKE 占位（含通配符 escape：`_` `%` `\` 转义），把「选中→搜索→附加笔记」交互链路跑通
- M6 换语义引擎时只改 search 实现，不动交互——里程碑解耦正确

### 4. 其他
- 颜色用 Pydantic 正则校验（^blue|yellow|green|pink$）
- /books/:id?para= 回跳定位（标注列表 → 阅读器）
