## 二、内存方案决策（本次评审的核心决策项）

**决策：选 A（接受 1.2GB 工作集）+ 记录技术债**

| 方案 | 内容 | 决策 |
|---|---|---|
| A | 接受 1.2GB（单机自用 MVP，无并发转写风险）| ✅ 采纳 |
| B | 每集转写放独立子进程，结束即释放内存 | 技术债，未来并发时再上 |
| C | 接受 + 记技术债 | 并入 A |

**决策理由**（产品视角）：
1. 自用单机 + 低频转写（导一集转一次），无并发需求——1.2GB 无实际影响
2. MVP 阶段优先功能完整性，不为未发生的压力优化
3. 求职叙事可讲：「评估过内存问题——转写低频一次性、单机无并发，接受工作集，记技术债；未来多并发再上子进程隔离」——理性取舍的产品判断

**风险提醒**：Intel Mac 内存若仅 8GB，转写时 1.2GB + 常驻 600MB 可能吃紧——转写时避免开多应用；实际卡顿则切 B 方案。
