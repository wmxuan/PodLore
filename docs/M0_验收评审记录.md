## 三、模型选型修正（Trae 实测发现 → 已吸收进开发指令）

| 发现 | 修正 |
|---|---|
| **SenseVoice 自带标点**（use_itn=True）| M2 方案改为 **2 个模型**（SenseVoiceSmall + fsmn-vad），**去掉 ct-punc**——避免「。。」「，，」双重标点 |
| **尺寸口径**：230MB=参数（2.3 亿）；fp32 磁盘 940MB；int8 内存 240MB | 验收改为「**运行时内存 < 600MB**」口径；诚实标注磁盘不小，优势在内存+速度+自带标点 |
| **m4a 解码需 ffmpeg** | 用 imageio-ffmpeg 静态二进制（仓库自足），M0.2 依赖 + M2 流水线第①步 |

**选型理由修正（面试可讲）**：选 SenseVoiceSmall 是因为「运行时内存小（int8 240MB）+ 非自回归速度快 + 自带标点」，不是磁盘小——讲真实口径，体现真懂。
